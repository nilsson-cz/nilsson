# Nilsson

Otevřený školní informační systém — jeden systém místo pěti. Vzniká pro
[ZŠ Vilekula](https://zsvilekula.cz) a nabízíme ho i dalším školám.

**Web produktu:** https://nilsson.cz

## Co to je

Nilsson spojuje agendy malé školy do jednoho nástroje: mapa pokroku žáka,
třídnice, docházka, družina, platby, obědy, výkazy pro kraj a další. Postavené
na Next.js + Supabase.

## Vztah k vývoji

Tohle je **veřejné zrcadlo vydaných verzí**. Vlastní vývoj probíhá v soukromém
repozitáři; sem přiletí každá vydaná verze jako jeden snapshot + tag (`vX.Y.Z`)
odpovídající tomu, co reálně běží v produkci. Průběžná vývojová historie tu proto
není — každý tag je čistý otisk dané verze. Jak přispět: [CONTRIBUTING.md](CONTRIBUTING.md).
